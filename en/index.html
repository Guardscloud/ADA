For small businesses and offices

It doesn't chat about the work. It does it.

Say what you need in plain language. ADA opens files, researches the web, uses the screen if it has to, and delivers the result as a Word, Excel or PDF file.

Invoices into a spreadsheet

Reads the PDF invoices in a folder and collects date, vendor, amount and tax into one Excel file.

Example"Scan the Invoices folder on my desktop, put them all into Excel and add a monthly total."

A summary every morning

Routines run by themselves every day. Industry news or the daily report is ready before you arrive.

Example"Every weekday at 09:00, summarise the news about my industry in a short report."

Market research report

Researches the web, compares competitors and prices, and writes a Word report with sources.

Example"Research the coffee shop market in my city, compare 5 competitors and write a Word report with sources."

File clean-up

Sorts messy folders by type and date and renames files so you can find them.

Example"Sort my Downloads folder into folders by type and name the PDFs by date."
Why ADA

Capable, and you stay in control

Speaks your language

The interface comes in 10 languages, including English and Turkish. ADA replies and writes documents in the language you write in.

Your data stays with you

ADA runs on your computer; there is no account and no server of ours. With local models such as Ollama or LM Studio, nothing leaves your machine.

Not tied to one model

The ADA-AGI router picks the right model for each job from your local models and the cloud keys you add (free Gemini, Claude, OpenAI, Groq…). Pick a model per message if you like; if one gets stuck, the job continues on the next.

Hide your IP with Tor

Offered on first launch: web searches and page reading go through Tor, so websites don't see your IP address. Say no and nothing is downloaded.

Approvals and emergency stop

You decide when ADA must ask first. One-click emergency stop, a log of every action, backups of changed files and the Watchdog that monitors your system.

Manage it from your phone

Pair the iPhone app with a QR code on the same Wi-Fi; give tasks, approve actions, see results and use a terminal from your phone.

How it works

Start in three steps

  1. Download and install

    On Windows run ADA-Setup.exe (a .dmg on Mac). No administrator rights needed.

  2. Connect an AI

    The easiest is a free Google Gemini key; paste it into the setup screen. Prefer no key? Use a local model with Ollama and ADA finds it by itself.

  3. Describe the job

    Write what you need in plain words. ADA works step by step, asks for approval when needed and delivers the result as files.

FAQ

Frequently asked questions

Is ADA free?

Yes, ADA is free to use. If you use a cloud AI provider, that provider may charge you; Gemini's free key and local models running on your computer cost nothing.

Where does my data go?

ADA runs only on your computer; you don't need an account and there is no server of ours. Your API keys and files stay on your machine.

With a cloud model, only the content needed for the job is sent to the provider you chose. With a local model (Ollama, LM Studio…), nothing leaves your computer.

Windows says "Windows protected your PC". Is it safe?

The installer is signed with our own certificate rather than a paid one Windows already knows, so SmartScreen shows an "unknown publisher" warning on first run. To continue:

  1. Click More info.
  2. Click Run anyway.

Only download the file from this page or the GitHub releases page.

Does it work on Mac and iPhone?

Mac: Yes. There are separate .dmg files for Apple Silicon (M1–M4) and Intel Macs. The Mac build is not notarized by Apple; if macOS blocks it on first launch, use System Settings → Privacy & Security → Open Anyway.

iPhone: the iPhone app is a companion to ADA on your computer: it pairs by QR code on the same Wi-Fi, and lets you give tasks, approve actions and open a terminal. It is not publicly available yet; coming soon.

Can it harm my computer?

By default ADA asks before risky actions, backs up the files it changes and logs every action. In safe mode, commands that would shut down the computer or wipe a disk never run. The emergency stop halts everything in one click.

ADA is still a young app, so keep backups of important data.

Is ADA open source?

Partly. ADA's plugin kernel, Open Kernel, is public on GitHub under the MIT license; you can add your own tools and rules with Python plugins. The core of the app is closed source.
